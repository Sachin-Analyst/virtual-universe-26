# Badge Story

This app contains Sachin's three-app badge menu. Select **Universe 26** to
open the animated congratulations screen with the Mona, starfield, title,
subtitle, and optional GitHub login from the Badge Simulator.

The congratulations artwork is bundled in this app's `assets` folder, so the
original `universe_congrats` app remains unchanged. Press any badge button after
the screen opens to return to the app menu.
